# 확정 후 이행

`.cursor/rules/commerce.mdc`를 읽는다. 단순 단품·즉시 배송에는 4층 모델을 강제하지 않는다.

## 절차

1. 고객이 확정(발급/받기)하기 전에는 공급사 주문·과금·산출물을 만들지 않는다.
2. 주문은 미확정으로 두고, 고객 표시명은 내부 카탈로그 표시명을 쓴다. 공급사 원본명을 알림/결제창에 넣지 않는다.
3. 수량이 여러 장·수신자가 여러 명이면 이행 자리를 주문 생성 때 펼친다.
4. 테스트도 사용자가 공급사 호출까지 승인한 경우가 아니면 1차 안내(링크)까지만.
5. 발송 후 검증: 주문 미확정, 안내 알림 1건, 산출물 0건.

완료: 확정 전에는 외부 원가가 나가지 않는다.
