# 랜딩·관리자 추가

`.cursor/rules/optional-web-surfaces.mdc`를 읽는다. 앱을 만든다고 해서 이 골격을 같이 깔지 않는다. **직접 요청된 뒤에만** 쓴다.

## 절차

1. 사용자 앱(폰 폭+하단 탭)과 코드베이스·레이아웃을 섞지 않는다. 별도 프론트 앱.
2. 랜딩은 와이드. 관리자는 테이블·필터. `app-ui-patterns`를 그대로 복사하지 않는다.
3. 관리자 API는 사용자 가드와 나눈다. 세션/JWT + 선택적 IP + 2차 OTP.
4. Railway 서비스를 그 앱용으로 추가한다. 기존 사용자 웹 서비스에 우겨 넣지 않는다.
5. 관리자를 SSR 껍데기 SPA로 강제하지 않는다.

완료: 요청한 면만 추가되고, 앱 셸은 그대로다.
